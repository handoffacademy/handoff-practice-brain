# Handoff practice brain

A practice brain for a made-up business, Sunny Days Cleaning, so you can try your AI team without your real email.

1. Choose **Use this template**, then **Create a new repository**.
2. Set it to **Private**.
3. Open claude.ai/code and start a session on your new copy.
4. Click the **+** next to the message box, choose **Connectors** and turn every connection off. The practice brain never uses them. The switches stay off in later sessions, so turn Gmail and Google Calendar back on for your real brain.
5. Type "Set me up".
