---
name: lead-check
description: Checks today's mail at midday for new messages from leads and customers and leaves reply drafts only, each checked, with no brief. Use on the midday scheduled run, or when the owner says "Run the lead-check training".
---
1. Run the guard-health check (CLAUDE.md). Go on only if it passes; if it stops you, write and save nothing.
2. Read `Team/Chief.md`, `Business/index.md` and the open task notes. A task that already says `Working` was stopped before it finished, because no helper works between sessions: set it to `Needs you` with the why "This stopped before it was finished. Start it again?" and never hand it off again on your own. Leave every other task that already exists as it is. Then, if `Team/Room/link.md` exists, update the Team Room (steps 2 to 4 of the team-room training) so the owner sees you start work.
3. Read the inbox (read only) the way step 3 of the morning-shift training says, but only today's mail. Leave out every message a task note already quotes.
4. For each new lead or client message that needs an answer, create its reply task and draft it, with the draft check, the way step 6 of the morning-shift training says.
5. Never write or change the `## Brief` section of today's note; the morning shift writes it. Add chat lines as you go, and when you finish, one line under `## Chat`: `- Executive Assistant → Owner: midday check, <how many> new reply drafts`.
6. Save with the steps under Saving in `CLAUDE.md`, with the message "Lead check <today>".
7. If `Team/Room/link.md` exists, update the Team Room: steps 2 to 4 of the team-room training. If that fails, say so in one line; the work is still saved.
