---
name: friday-review
description: Weekly review of the team's work. Use on the Friday scheduled run or when the owner asks how the week went.
---
1. Read this week's notes in `Team/Chat/` and all task notes.
2. Write a short review at the top of today's chat note under `## Brief`: what ran, what is still waiting, one thing to improve.
3. Run the tidy-the-brain training.
4. Suggest one change to one job page as a task note (`status: Needs you`, `owner: Chief`, the exact wording in the body). Never edit a job page yourself.
5. Save (Saving in CLAUDE.md).
