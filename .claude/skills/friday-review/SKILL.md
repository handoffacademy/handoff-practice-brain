---
name: friday-review
description: Reviews the week, tidies the notes and suggests one improvement. Use on the Friday scheduled run, when the owner says "Run the friday-review training", or when the owner asks how the week went.
---
1. Run the guard-health check (CLAUDE.md). Go on only if it passes; if it stops you, write and save nothing.
2. Read this week's notes in `Team/Chat/` and all task notes. A task that already says `Working` was stopped before it finished, because no helper works between sessions: set it to `Needs you` with the why "This stopped before it was finished. Start it again?" and never hand it off again on your own. Then, if `Team/Room/link.md` exists, update the Team Room (steps 2 to 4 of the team-room training) so the owner sees you start work.
3. Write a short review in today's chat note under its own heading `## Friday review`, below `## Brief` when the note has one: what ran, what is still waiting, one thing to improve. Never change the `## Brief` section; the morning shift writes it.
4. Run the tidy-the-brain training.
5. Suggest one change to one job page as a task note (`status: Needs you`, `owner: Executive Assistant`, the exact wording in the body). Never edit a job page yourself.
6. Save (Saving in CLAUDE.md).
7. If `Team/Room/link.md` exists, update the Team Room: steps 2 to 4 of the team-room training. If that fails, say so in one line; the work is still saved.
