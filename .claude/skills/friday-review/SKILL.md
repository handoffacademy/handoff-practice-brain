---
name: friday-review
description: Reviews the team's week, tidies the notes and suggests one improvement. Use on the Friday scheduled run, when the owner says "Run the friday-review training", or when the owner asks how the week went.
---
1. Read this week's notes in `Team/Chat/` and all task notes. Then, if `Team/Room/link.md` exists, update the Team Room (steps 2 to 4 of the team-room training) so the owner sees the Chief start work.
2. Write a short review in today's chat note under its own heading `## Friday review`, below `## Brief` when the note has one: what ran, what is still waiting, one thing to improve. Never change the `## Brief` section; the morning shift writes it.
3. Run the tidy-the-brain training.
4. Suggest one change to one job page as a task note (`status: Needs you`, `owner: Chief`, the exact wording in the body). Never edit a job page yourself.
5. Save (Saving in CLAUDE.md).
6. If `Team/Room/link.md` exists, update the Team Room: steps 2 to 4 of the team-room training. If that fails, say so in one line; the work is still saved.
