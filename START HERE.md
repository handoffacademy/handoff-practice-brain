# Start here

This is your brain: everything your Executive Assistant knows about the business.
To talk to your assistant, open claude.ai/code, start a session on this copy, and type "Catch me up".
New here? Type "Set me up" and your assistant walks you through it, one step at a time.
Drop anything new into **Drop Zone**. Your assistant files it.
Anything that needs you is a task marked "Needs you" in **Team/Tasks**.
Open this brain only in a regular Claude Code session or a scheduled task on this copy: its safety guard runs only there.
